# Logralee

Promotional landing page for the **Logralee** app — static **GitHub Pages** site (this repo).

## GitHub Pages

**Settings → Pages → Deploy from branch** → `main` / `/ (root)`.

Live site: **https://gonzalezosv.github.io/logralee/**

## Assets

Files in `assets/` include placeholder phone screenshots from [placehold.co](https://placehold.co). Replace them with your real app captures (same filenames) before sharing widely.

## Local preview

Open `index.html` in a browser, or run a static server from this folder.
