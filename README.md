# logralee.com

Marketing site for the **Logralee** app (Bit Ray Technologies). Static HTML + one CSS file + a 4.5 KB script,
deployed on **Cloudflare Pages** with a Pages Function and D1 for the waitlist.

- `index.html` — the page. Edit `index.src.html`, then `python3 tools/build_index.py`.
- `features/ privacy/ terms/ support/ press/ joined/` — generated by `python3 tools/pages.py` from `tools/pages/`.
- `assets/` — CSS, JS, images (AVIF/WebP), icon sprite, wordmark.
- `functions/api/waitlist.ts` — POST → D1. `schema.sql`, `wrangler.toml`.
- `docs/` — brief, feature facts (the only source of truth for claims), design spec, review mocks.

**Setup, deploy, launch-day switch and asset slots: see [BUILD_NOTES.md](BUILD_NOTES.md).**

Preview: open `index.html` in a browser. Everything works except the waitlist post, which needs the Function:

```bash
wrangler d1 execute logralee-waitlist --local --file=./schema.sql
wrangler pages dev . --port 8788
```

Pre-deploy checks (overflow at 13 widths, weight budget, screenshots): `python3 tools/check.py http://localhost:8788`.
